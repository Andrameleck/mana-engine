About

Mana-Engine

A Magic: The Gathering deckbuilding API built around a generalized, explainable, mechanics-first synergy engine. It identifies which cards work together — and why — by modelling cards through their normalized mechanical behaviour: what events they produce, reward, consume, replace or prevent.

The engine supports direct synergies, group / package detection, role-aware bidirectional scoring, anti-synergy modelling, and integration with public combo databases. Results always include human-readable explanations, not just numeric scores.

Status: active development — APIs and output schemas may change.

Synergy engine

Mechanics-first

Cards are represented through normalized structures — produces, rewards, requires, replaces, prevents, amplifies — mapped from Oracle text and keyword expansion. Synergy scoring is role-aware and bidirectional: each card's role (engine, payoff, fuel, tool, protection…) is inferred from the pair, not from which card was the input.

  • Role-aware pair scoring
  • Package / line detection
  • Anti-synergy modelling
  • Keyword expansion
  • Group scoring
Data sources
  • Scryfall Card data, Oracle text, images, autocomplete & localization API
  • Commander Spellbook Public combo database — infinite combos & synergy clusters
  • MTGJSON Comprehensive machine-readable card and set data
  • LotusNoir French MTG community deck lists — cross-validation signal (beta)
  • Manabox / Archidekt / Moxfield Collection CSV export sources supported for import
Tech stack
  • R Core language — synergy engine, API logic, data pipelines
  • Plumber HTTP API framework for R — routes, middleware, serialization
  • Vite Frontend build tool — bundles the SPA served at /ui/
  • DBI + RSQLite Persistent storage for collections, deck lists and synergy cache
